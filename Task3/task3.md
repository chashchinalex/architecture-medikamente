# Политика защиты данных: шифрование при хранении и передаче

## 1. Классификация информации

### 1.1 По уровню конфиденциальности

| Уровень | Характеристика | Примеры | Потенциальные последствия |
|--------|----------------|---------|----------------------------|
| **L1 — Критический** | Особые категории ПДн и медицинские сведения | Меддосье, результаты обследований | Наиболее серьёзные риски при утечке |
| **L2 — Высокий** | Персональные данные | ФИО, паспортные реквизиты, СНИЛС, контакты | Правовые санкции и регуляторные нарушения |
| **L3 — Средний** | Операционные и финансовые данные | Расчёты, договоры, выплаты | Возможные финансовые убытки |
| **L4 — Низкий** | Внутренние материалы | Графики, прайс-листы | Ограниченный ущерб |

### 1.2 По состоянию

| Состояние | Определение | Основные угрозы |
|-----------|-------------|-----------------|
| **At Rest** | Информация, размещённая в хранилищах | Несанкционированный доступ, компрометация носителей |
| **In Transit** | Данные, передаваемые по сети | Перехват, подмена трафика |
| **In Use** | Информация в процессе обработки | Доступ к памяти, побочные каналы |

## 2. Обоснование защиты и применяемые меры

| Тип данных | Уровень | Состояние | Основание | Средства |
|------------|---------|-----------|-----------|----------|
| Медицинские карты | L1 | At Rest | Охрана врачебной тайны | TDE (AES-256), выделенная БД, RBAC |
| Анализы | L1 | At Rest / In Transit | Передача между системами | AES-256, TLS 1.3, защитные API |
| Диагнозы | L1 | At Rest | Чувствительность PHI | AES-256, ABAC |
| ФИО | L2 | At Rest / In Transit | Требования ФЗ-152 | AES-256, TLS 1.3, маскирование |
| Паспорт | L2 | At Rest | Риск мошенничества | AES-256, ограничение доступа |
| СНИЛС | L2 | At Rest | Используется для идентификации | AES-256, токенизация |
| Контакты | L2 | Оба | Используются в коммуникациях | AES-256, TLS 1.3 |
| Адрес | L2 | At Rest | Сведения о местоположении | AES-256, минимизация хранения |
| Карты оплаты | L3 | In Transit | Требования PCI DSS | TLS 1.3, токенизация |
| История платежей | L3 | At Rest | Финансовые сведения | AES-256, аудит |
| Договоры | L3 | At Rest | ПДн + финусловия | AES-256, контроль версий |
| HR-данные | L3 | At Rest | Сведения сотрудников | AES-256, RBAC |
| Учётные записи | L2 | At Rest | Ключ к системе | Argon2/bcrypt, HSM |
| Логи | L3 | At Rest | Доказательная база | Неизменяемое хранение |
| Сессионные токены | L2 | In Transit / In Use | Угроза перехвата | JWT, малый TTL, TLS |
| Расписание | L4 | At Rest | Служебная информация | Базовое шифрование |
| Прайс | L4 | At Rest | Публичность | Не требует шифрования |

## 3. Средства защиты

### 3.1 Хранение (At Rest)

| Средство | Назначение | Применение |
|----------|------------|-------------|
| PostgreSQL TDE | Прозрачное шифрование | Базы с ПДн |
| AES-256-GCM | Шифрование файлов | Документы, изображения |
| Vault | Управление ключами | Централизованное хранение |
| LUKS | Шифрование дисков | Серверная инфраструктура |
| KMS | Ключи в облаке | Облачные среды |

### 3.2 Передача (In Transit)

| Средство | Назначение | Область |
|----------|------------|----------|
| TLS 1.3 | Шифрование трафика | API, веб, мобильные сервисы |
| mTLS | Двусторонняя проверка | Межсервисные соединения |
| WireGuard / IPSec | Защищённые каналы | Филиалы, VPN |
| HTTPS enforcement | Принудительный HTTPS | Балансировщики |

### 3.3 Использование (In Use)

| Средство | Назначение | Применение |
|----------|------------|-------------|
| SEV / SGX | Защита памяти | Критичные операции |
| Secure Enclaves | Изолированная обработка | Работа с PHI |

## 7. Этапы внедрения

### Приоритет 1 — незамедлительно
- Активация TLS 1.3 во внешних интерфейсах
- Включение TDE в БД с PHI/PII
- Развёртывание Vault для управления ключами

### Приоритет 2 — в течение месяца
- Настройка mTLS для внутренних сервисов
- Подключение pgAudit
- Развёртывание SIEM

### Приоритет 3 — в течение квартала
- Внедрение DLP
- Рассмотрение использования HSM
- Автоматизация ротации ключей и сертификатов
