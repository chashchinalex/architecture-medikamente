# Список проблем компании в разрезе работы с данными

## 1. Стратегические проблемы
1. Отсутствие централизованной архитектуры данных и единых правил обработки.
2. Неопределённость моделей данных, отсутствует классификация (PII, медицинские данные, финансовые данные).
3. Отсутствие политики жизненного цикла данных (Data Lifecycle).
4. Отсутствие Data Governance, владельцев данных и процессов контроля качества.

## 2. Проблемы безопасности
1. Отсутствие шифрования данных в покое и при передаче.
2. Доступ к данным обеспечивается «по факту владения файлом» — отсутствует RBAC/ABAC.
3. Нет журналирования доступа и аудита операций с данными.
4. Внутренние потоки данных между системами не контролируются.
5. Нет защиты от несанкционированного копирования (DLP отсутствует).
6. Отсутствует мониторинг инцидентов и аномальной активности.

## 3. Проблемы хранения и интеграции
1. Массовое использование Excel, JPG, PDF как основного хранилища данных.
2. Отсутствие проверенных API-контрактов — интеграция лаборатории полностью ручная.
3. Нет Data Lake, данные не готовы для BI/ML/AI.
4. Нет контроля версий файлов и целостности данных.
5. Передача данных через почту и файловые серверы без защиты.

## 4. Операционные проблемы
1. Большой объём ручной работы сотрудников.
2. Невозможность сегментации данных и ограничения доступа по ролям.
3. Отсутствие автоматизации записи пациентов и процессов уведомлений.
4. Отсутствие возможности маркировать данные по уровню чувствительности.
5. Отсутствие проверки систем на корректную работу с конфиденциальными данными.

## 5. Проблемы соответствия будущим требованиям
1. Текущее состояние не позволяет безопасно интегрировать сторонние системы.
2. Мобильное приложение не может быть реализовано без механизмов контроля доступа.
3. Архитектура не масштабируется при росте филиалов и числа пользователей.
4. Отсутствуют механизмы автоматического удаления данных по запросу субъекта ПДн.
